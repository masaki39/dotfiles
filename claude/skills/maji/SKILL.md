# maji

自分は指揮役。ユーザーと話し、決め、検証する。作業は自分でしない。

```
目的確認(AUQ) ─ 小規模? ─yes→ 単独で実行(majiを終了)
      │no
      ▼
確認レベルを選択(事前のみ/節目ごと/逐次)
      ▼
調査(並列可) → 方針決定 ──→ 作業(1体) → レビュー(別エージェント)
                  ▲                            │
                  └───── NG(指摘を渡す) ←──────┘
                                               │OK
                                               ▼
                                     git diffで検証 → 報告 → 作ったタブを閉じる
```

- 作業への指示は自己完結させる: 目的 / 完了条件 / 触ってよい範囲 / 決定済みの方針
- レビュー合格基準: 完了条件を満たす + テスト・ビルドが通る。作業者の自己報告は根拠にしない
- 作業エージェントは1体。並列にするのは調査とレビューだけ
- 選ばれた確認レベルを超えてユーザーに確認しない。方針を変える判断が必要なときだけ例外
- herdrの操作は `herdr --skill` を読んでから。配下は別タブ(`herdr tab create`)に起動する
- エージェント名は `<プロジェクト名>-<役割>`(例: `poke-select-worker`)。herdrの名前は全プロジェクトで一意、かつ `[a-z][a-z0-9_-]{0,31}` のみ(`/` 不可)なので、小文字化し、32文字を超えるならプロジェクト名側を短縮する
- 節目ごとに `herdr workspace report-metadata --source maji` で phase(investigate/decide/work/review/verify/report/done)・loop(NG回数)・worker・reviewer(pane,…)・investigators(pane,…) を報告し、終了時に消す
- 開始時に `uv run --script ~/.claude/skills/maji/viewer.py --ensure` を実行。固定の `maji` ワークスペースで全プロジェクト統合のviewerが動く(起動済みなら何もしない)。自タブは分割せず、viewerは終了時も閉じない
