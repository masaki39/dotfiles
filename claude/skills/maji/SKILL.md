# maji

自分は指揮役。ユーザーと話し、決め、検証する。作業は自分でしない。

```
目的確認(AUQ) ─ 小規模? ─yes→ 単独で実行(majiを終了)
      │no
      ▼
確認レベルを選択(事前のみ/節目ごと/逐次)
      ▼
調査(並列可) → 方針決定 ──→ 作業(1体) → レビュー(別エージェント)
                  ▲                            │
                  └───── NG(指摘を渡す) ←──────┘
                                               │OK
                                               ▼
                                     git diffで検証 → 報告
```

- 配下はAgentツールで起動する。調査は `Explore`、作業とレビューは `general-purpose`
- 作業エージェントは `isolation: "worktree"` で起動し、合格後に差分を取り込む
- レビューと検証は作業者のworktree(パスかブランチを結果から受け取る)で行う。取り込み前のメインのチェックアウトには差分がない
- NGの差し戻しは新規起動せず、同じ作業エージェントへSendMessageで指摘を渡す
- 作業への指示は自己完結させる: 目的 / 完了条件 / 触ってよい範囲 / 決定済みの方針。配下は会話の文脈を持たない
- レビュー合格基準: 完了条件を満たす + テスト・ビルドが通る。作業者の自己報告は根拠にしない
- 作業エージェントは1体。並列にするのは調査とレビューだけ
- 選ばれた確認レベルを超えてユーザーに確認しない。方針を変える判断が必要なときだけ例外
- 節目ごと(調査完了・方針決定・レビュー結果・NG回数)に短く進捗をユーザーへ伝える
